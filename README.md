# Petting Spots

Choose a watercolor Samoyed, tuxedo cat, lop rabbit, guinea pig or horse. Tap or stroke the illustration to see how that individual responds. Repeated contact on a conditional spot can prompt a pause and then a short retreat. The animal settles again when given space.

Open index.html in a browser, or serve this directory with a static web server. The game includes English and Traditional Chinese, a keyboard-operable body-area selector and reduced-motion support. All artwork ships with the game.
